# Founder dashboard design adaptation

Source: Jadon's [Founder Overview, frame 66:4611](https://www.figma.com/design/WKKcQuHiUXj9ujmglwnYOc/arize-prototype--mockups?node-id=66-4611).

The implementation retains the 232px dark-green sidebar, cream canvas, Nunito typography, four white headline cards, activity chart, feature bars and membership strip. At narrow widths, navigation wraps above a two-column KPI grid and stacked charts. The final original logo is used, not a new mascot.

The original frame's school/student labels are adapted for this **adult** view. No school filter, counselor statistic, placeholder content tab or fabricated figure is rendered. Student remains explicitly disconnected. Profile is an account link; the supplied asset is a plain avatar placeholder, not a person's photo.
